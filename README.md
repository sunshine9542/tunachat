# 기억에 남는 선물 - 콘티크 웹앱

녹음 항목별 계속 / 신문을 받았을 때의 기분. 선물을 준 이유 추측

## 실행 방법

1. **터미널에서 프로젝트 폴더로 이동** (필수):
```bash
cd /Users/sook.com/Downloads/떠나찾wep_app   # 또는 tunachat 프로젝트 폴더
```

2. **로컬 서버 실행**:
```bash
python3 -m http.server 8080
```

3. **브라우저에서 접속**:
   - http://localhost:8080/
   - 또는 http://localhost:8080/index.html
   - 테스트: http://localhost:8080/test.html (이게 보이면 서버 정상)

4. 아무것도 안 보이면:
   - 서버를 실행한 터미널의 현재 폴더가 프로젝트 루트(tunachat)인지 확인
   - 브라우저에서 F12 → Console 탭에서 에러 확인
   - 단, 녹음 기능은 HTTPS 또는 localhost 환경에서만 동작합니다.

## 주요 기능

- **레코딩 홈**: 인기 콘텐츠, 활동한 콘텐츠 목록
- **콘텐츠 상세**: 녹음/재생, 파형 시각화, 저장 (내 활동에 저장)
- **저장 확인**: 저장 후 공유하기(게시물 작성) 또는 홈으로
- **녹음 미완료 경고**: 재녹음 불가 안내 팝업
- **게시물 작성**: 콘텐츠 표지, 녹음본 선택, 본문, #태그
- **공유 게시판**: 모든 콘텐츠 필터, 게시물 목록 (최신순)
- **게시물 상세**: 본문, 사진, 오디오, 좋아요, 댓글, FAB(녹음하러가기, 드로잉&라이팅)
- **My Contents**: 재녹음 (이전 녹음본 삭제, 게시물 보존)
- **내 활동**: 활동 중 촬영한 사진들, 최신순/콘텐츠순 정렬

## 하단 네비게이션
